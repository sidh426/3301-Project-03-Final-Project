# Project Retrospective

## What Went Well
Having a clear Project Scope Statement written before any code was built made the biggest difference. Because "done" was defined up front, in acceptance criteria, exclusions, and constraints, I was not guessing mid-project about what was in or out of scope. Deploying to GitHub Pages early with placeholder content also paid off, since it meant any hosting issues surfaced early instead of becoming a last-minute panic before the deadline.

## What Went Wrong
The stylesheet task took longer than the WBS estimated. Getting the hero section's two-column layout to collapse cleanly into a single column on mobile required more trial and error with the grid and media query than I had planned for, since content that looked fine on desktop was initially cramped and misaligned on smaller screens. I also underestimated how long it would take to write genuinely specific content for the About page rather than generic placeholder text, pulling real detail from my internship work took more thought than expected.

## What I Would Do Differently
Going back to the "cadence of accountability" idea from PMUPM Chapter 6, I would build in shorter, more frequent check-ins with myself throughout the project rather than only reflecting at major milestones. This mirrors the lesson from Range about treating a project as an evolving process rather than a fixed plan executed exactly as scoped. On a future project, I would also budget explicit time for testing and polish rather than treating it as something that happens automatically at the end of development.

## Connection to Course Themes
This project pulled together the full arc of the course: writing a scope statement to define the project (Chapter 3), analyzing risk with the TAME framework (Chapter 4), planning a realistic task breakdown, and using GitHub as both a version control tool and an accountability mechanism (Chapter 5). The "range" mindset from Epstein showed up less in any single skill and more in how differently sourced experience, coursework, my internship, and this class's technical content, all had to come together to actually ship something.
